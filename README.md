# FRAME — Premium Image Gallery

A responsive photography gallery made for the CodeAlpha Frontend Development task.

## Included files
- `index.html` — page structure and lightbox markup
- `style.css` — premium dark theme, responsive layout, hover effects and transitions
- `script.js` — gallery rendering, category filters and lightbox navigation

## Requirements covered
- HTML/CSS gallery layout
- Previous/next lightbox controls
- Smooth hover effects and transitions
- Responsive desktop, tablet and mobile layouts
- Nature, Architecture, Travel and Wildlife filters
- Keyboard navigation: Left/Right arrows and Escape
- Mobile swipe navigation in the lightbox

## Upload to GitHub Pages
1. Extract this ZIP.
2. Open your GitHub repository `image-gallery-`.
3. Choose **Add file → Upload files**.
4. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root (not inside another nested folder).
5. Commit the changes.
6. In **Settings → Pages**, ensure it deploys from your main branch and root folder.
7. Wait for deployment, then refresh the live page with Ctrl+F5.

## Important
The photos are loaded from Unsplash image URLs, so the browser needs an internet connection to display them. Replace the URLs in `script.js` if you want to use your own uploaded image files.
